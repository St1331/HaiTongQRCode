# ADR-0002：实时核验缓存与本机容器验收

- 状态：Accepted
- 日期：2026-09-07

## 背景

当前没有可主动清除的 CDN/共享缓存。公开接口的 `s-maxage=60` 与二维码 PNG 的五分钟缓存会让作废或轮换后的旧信息继续被使用。容器需在本机 HTTP 下进行测试，但正式域名必须使用 HTTPS。

## 决策

- 公开核验响应使用 `Cache-Control: no-store`；后台二维码使用 `private, no-store`。浏览器二维码 URL 同时包含 revision，确保轮换后重新请求图片。将来引入缓存必须先实现可靠主动失效和对应测试，再通过新 ADR 调整。
- 生产模式的公开地址必须为 HTTPS 并使用 Secure Cookie。仅当 `ALLOW_LOCAL_HTTP=true` 且主机为 localhost/loopback 时，允许生产构建在本机 HTTP 测试；该开关不允许外部域名使用 HTTP。
- 公开地址不接受内嵌凭据、路径、查询参数或片段。会话与 IP HMAC 密钥必须不同，生产拒绝示例密钥。
- 审计日志由新增 migration 的触发器禁止 UPDATE/DELETE；数据库维护账号的权限与备份恢复仍由运维管理。

## 影响

核验请求总是查询当前数据库状态，需要在容量验收中覆盖无共享缓存的负载。原 API 缓存契约由本决策替代。已有数据保持不变，新增审计触发器通过 migration 前滚和回滚；运维恢复应保留触发器保护。
