# T3 登记记录交互修复

- 日期：2026-09-07；分支：`fix/T3-record-controls`，基于本地 T8 修复提交。
- 用户反馈：登记记录页面搜索、下拉栏及按钮的功能不完整或操作效果不明确。

## 修复内容

- 搜索支持回车及查询按钮，去掉关键词首尾空格；相同条件再次查询也会请求最新数据。
- 类型、状态和业务日期选择后立即筛选，条件变化返回第一页；起始日期晚于截止日期时显示提示，不发送无效范围查询。
- 接通后端已有的排序字段、升降序、每页 10/20/50/100 条和分页能力。越界空页仍可返回第一页。
- 筛选状态保存在 URL，前进后退时输入框与结果同步；清空同时重置所有筛选和分页参数。
- 查询失败显示独立错误及重试，不再同时显示误导性的“暂无匹配记录”。查询期间按钮显示加载状态。
- 登记列表不沿用全局 15 秒新鲜期，重新进入列表时重新取数，避免编辑后短暂显示旧内容。
- 新建取消回到列表，编辑取消回到对应详情；保留未保存确认、角色权限和防重复提交保护。
- 表格在窄屏内横向滚动，分页允许换行，避免表格文字及分页页码被挤成竖排。

`apps/web/src/app/admin/records/page.tsx`、`apps/web/src/components/record-form.tsx`、`apps/web/src/app/globals.css`、`apps/web/e2e/record-controls.spec.ts`。
