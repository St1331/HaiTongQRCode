# HaiTongQRcode

招标文件与合同二维码登记、核验和追溯系统。

## 当前状态

项目处于 P0（需求与工程决策冻结）阶段，尚未开始功能开发。

## 核心流程

```text
后台登记招标文件或合同 -> 发布 -> 生成二维码 -> 公众扫码 -> 核验最新状态与公开信息
```

系统提供企业登记信息核验，不替代电子签章、CA 认证或司法意义上的原件鉴定。
